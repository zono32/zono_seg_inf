Máquinas virtuales y Dominios

Introducción

En esta tarea vamos a configurar un dominio con Windows Server y a unir una máquina Linux Mint al dominio creado. Para ello vamos a usar Virtual Box para crear las máquinas virtuales necesarias. El dominio nos permitirá gestionar usuarios y permisos de acceso a recursos de la red de manera centralizada.
