Protocolos de seguridad:

Hoy en día somos más y más los que utilizamos las nuevas tecnologías para comunicarnos y buscar información, con ello buscamos la rapidez de las comunicaciones y por supuesto la seguridad de nuestros datos. Para ello siempre hay trabajando en segundo plano protocolos que cifran la información y verifican que los servicios que usamos son quien en realidad dicen ser. Sin estos protocolos nuestros datos estarían expuestos a cualquiera en la red.

Protocolo https://

El protocolo https:// que consta del protocolo http:// que es el que se encarga de transmitir la información, con el TLS que es el que se encarga de que esa transmisión sea segura. Este protocolo se utiliza en el día a día para navegar por redes sociales, hacer compras o leer noticias. Funciona cifrando la comunicación entre nuestro navegador y el servidor, para que la información no sea legible para un tercero.

Protocolo IPsec, OpenVPN y Wireward

Tenemos por otro lado el IPsec, OpenVPN y el Wireward. Este protocolo se usa para las VPN (Virtual, Protocol, Network). Lo usamos a diario para el teletrabajo, así nos permite unirnos a una red privada a distancia. También la usamos para proteger nuestra privacidad. Funciona creando un túnel privado a través de internet cifrando toda la información que sale de nuestro equipo.

Protocolo SSH

El SSH (Secure Shell). Este protocolo se utiliza para para acceder a los equipos de forma remota A diario lo utilizan los administradores de sistemas o programadores para subir código a plataformas como github… O para acceder a servidores o otros equipos de forma remota. Permite ejecutar comandos en otra máquina de forma segura.

Protocolo WPA3

WPA3 (Wi-Fi Protected Access 3) este protocolo se utiliza para realizar conexiones a internet de forma segura El uso diario que le damos es el de conectarnos a la WIFI de la casa o de un bar. Este protocolo protege tu conexión inalámbrica para que nadie pueda interceptar los datos a través del aire.

Protocolo IMAPS, POPS, SMTPS

El IMAPS, POPS, SMTPS, son protocolos de correo seguro. Lo utilizamos cuando usamos plataformas de correo tipo Outlook o Gmail, El IMAPS y el POPS, se utilizan para cifrar los correos mientras que el SMTPS, se encarga de que los correos no sean interceptados en el camino.
